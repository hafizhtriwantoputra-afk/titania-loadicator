BV-stamped Test Loading Conditions Rev.A. Cargo is entered as TOV (m³) so the result can be compared with CAMEL line by line.

Settings

CAMEL uses weight = GSV × density (no −0.0011). Leave this off to match CAMEL.

Draft display

Both are extreme drafts (from the underside of the keel). Perpendiculars: AP −48.90 m, FP +48.90 m from midship, as CAMEL's main figures. Draft marks: aft −37.50 m, mid +1.27 m, fwd +45.15 m, the figures you read on the hull.

Trim for sounding correction

Rounding

COT 1–5 use the trim correction tables from the calibration certificate (COWONB2401371-02 Rev.0), trim −1.0 to +4.0 m (book in mm), interpolated on trim and sounding. Interpolated rounds the correction to the nearest 1 mm (e.g. −17.36 → −17 mm). Whole cm rounds it to whole centimetres as in the ship's ullage report (−17.36 mm → −2 cm). Calculated repeats the calculation until the trim used for the correction equals the resulting trim. Slop and residual tanks have no trim table and are not corrected.

Ullage reference height

Ullage = reference height − sounding. Default is the top of the calibration table. Set it to the value in the calibration book.

About the calculation

Version 2, planning aid. Official documents remain the approved CAMEL output.

Data sources: CAMEL Stored Data Rev.A (BV): hydrostatics and cross curves per trim, tank tables, lightweight distribution, frame spacing, strength limits, wind and flooding data. Bonjean's Table (100-005). SGS cargo tank calibration tables and trim corrections (COWONB2401371-02). Loading Manual §2.2–2.3 for the IS Code 2008 criteria.

Method: free-trim equilibrium (LCB = LCG) from the trim tables, as CAMEL does. GZ from KN with free surface: constant FSM for consumables and ballast, real liquid shift for slack cargo tanks, nominally full (≥98%) cargo tanks per Loading Manual §2.3.2.

Check against the 4 CAMEL test conditions: drafts, trim, KMT and GM fluid equal to CAMEL within 0.002 m. IS Code areas and GZ within 0.01 (slack cargo slightly on the safe side). SF/BM use a correction calibrated on these conditions; a cross-check on conditions not used for calibration gave SF within 6 t and BM within 1% of the allowable.

Propeller immersion from Stored Data p.5 (tip 3.55 m above keel at −46.5 m) and Loading Manual (Zs 2.20 m, Dp 2.70 m). Visibility per SOLAS V/22 from Stored Data p.15 (eye 21.0 m at −31.05 m, bow chock 14.1 m at 52.317 m). Both match the CAMEL test conditions.

Not included: damage stability.
